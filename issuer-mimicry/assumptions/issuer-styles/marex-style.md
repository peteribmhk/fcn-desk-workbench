# Marex-Style Pricing Assumptions

**Status:** Inferred from market observation.

## Known Characteristics

- Higher coupons on aggressive baskets (emerging tech, biotech)
- Wider on correlation (conservative worst-of)
- Higher funding spread
- Willing to price less liquid names

## Parameters

| Parameter | Value |
|-----------|-------|
| skew_markup | 3.5% |
| correlation_haircut | 12% |
| funding_spread | 100bp |
| profit_margin | 60bp |
| dividend_drag | 60bp |
| borrow_cost | 30bp |

## When to Use

- Aggressive/high-vol baskets
- Emerging tech or biotech
- When other issuers decline to quote
